# Building Memo

Fynnestlady is a skincare e-commerce business. Build for humans first.

Understand the user before designing the screen. Understand the business requirement before implementing the feature. Security and correctness are release requirements. Accessibility is not optional. Mobile is not a secondary experience. Premium visual quality is required.

Do not overengineer. Use a modular monolith unless evidence demonstrates a need for greater distribution. Do not introduce microservices for architectural prestige, Kubernetes, or needless infrastructure. Prefer boring, well-understood technology over unnecessary novelty.

Do not create features without a defined business or user outcome. Never use AI-generated filler as verified product information. Never fabricate skincare claims, product information, evidence, or completion. Preserve maintainability and verify before claiming success.

Every execution plan, remediation plan, development plan, and roadmap must reference this memo unless Eric Appiah Owusu explicitly says otherwise.

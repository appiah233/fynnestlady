# Contributing

Read `RULES.md`, the building memo, project governance, architecture, and coordination records before work. Claim a scoped task in `docs/coordination/ACTIVE_WORK.md`, use a non-main branch and conventional commits, preserve unrelated work, and submit the pull-request template with reproducible evidence.

Required specialist reviews depend on impact. UI requires DesignAgent; schema requires DatabaseAgent; identity, payment, uploads, customer data, secrets, and infrastructure require SecurityAgent; significant architecture requires ArchitectAgent. TestingAgent independently verifies critical behavior.

Only Eric Appiah Owusu may merge or authorize production deployment.

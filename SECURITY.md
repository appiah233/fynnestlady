# Security Policy

Do not disclose suspected vulnerabilities in public issues. Report them privately to the repository owner, Eric Appiah Owusu, using a private GitHub security advisory when available.

Include affected component, impact, reproduction steps, evidence, and suggested containment without including live credentials or customer data. Do not test against production or access data beyond what is necessary and authorized.

Critical/high verified issues block release unless the owner records explicit risk acceptance. Security controls and reporting expectations are defined in `docs/architecture/SECURITY_MODEL.md` and `docs/architecture/THREAT_MODEL.md`.
